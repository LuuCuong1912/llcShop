# LCShop

## Project Overview

LCShop là dự án Portfolio cá nhân được phát triển nhằm mô phỏng một website bán đồ công nghệ hướng tới môi trường doanh nghiệp.

Mục tiêu của dự án:

- Học quy trình phát triển phần mềm.
- Tự phân tích nghiệp vụ.
- Tự thiết kế Database.
- Tự xây dựng Frontend và Backend.
- Hoàn thành Portfolio xin việc.
